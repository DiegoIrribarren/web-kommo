# Ecosistema Web + Kommo CRM

Plataforma web escalable diseñada en dos etapas para captación de leads y automatización comercial con Kommo CRM.

## Estructura del Proyecto
- `/frontend`: Aplicación React + Vite (Etapa 1: Landing page, captura de UTMs y conexión a WhatsApp/Salesbot).
- `/backend`: Servidor API REST v4 y receptor de Webhooks de Kommo (Etapa 2).
- `/docs`: Mapeo técnico de IDs y flujos del CRM.

## Ejecución Local (Frontend)
1. Entrar a la carpeta: `cd frontend`
2. Instalar dependencias: `npm install`
3. Levantar entorno de desarrollo: `npm run dev`
